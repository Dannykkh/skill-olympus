01 / SYSTEM MAP

先说明连接了什么，也说明边界在哪里。

Olympus 不会把所有主机都称为完整集成。4 个 CLI 具备经过验证的运行时集成，另外 2 个主机只安装可移植技能。

Integrated

Claude Code、Codex CLI、Antigravity CLI 和 Grok Build 分别遵循对应运行时的安装、记忆与编排契约。

Skills-only

OpenClaw 与 Hermes Agent 安装 18 个活跃技能和 76 个 source-only 模块。

02 / ENTRY POINTS

只调用任务需要的深度。

平时只显示 18 个入口。76 个专业模块仅在任务确实需要时，才从目录中读取。

01Zeus/zeus

从一句需求推进到设计、实现、验收、运行环境、测试和证据报告。

02Zephermine/zephermine

在实现前固定需求、API、QA 场景和流程图。

03Poseidon/agent-team

把文件归属分配给当前 CLI 的原生工作者，并行实现。

04Aphrodite/aphrodite

从用户任务出发，完成体验契约、实现和实际渲染检查。

05Argos/argos

对照设计产物验收实现，并给出有证据的通过或不通过结论。

06Minos/minos

运行 Playwright 场景，修复可复现失败，直到检查通过。

07Chronos/chronos

逐项推进，直到外部验证证据满足完成契约。

08Mnemo/mnemo

查找过去的会话与决策，为下一次会话留下可恢复状态。

03 / SUPPORT

明确区分支持等级。

能够读取技能文件，并不等于已经接入 hooks、记忆、MCP 和原生工作者。页面会一直保留这条边界。

04 / INSTALL

TermSnap 一次安装，其他主机明确选择。

默认安装器会准备 Claude、Codex、Antigravity 和 Grok。OpenClaw 与 Hermes Agent 使用各自的 skills-only 安装器。

Clone
git clone https://github.com/Dannykkh/skill-olympus.git
cd skill-olympus
Windows · integrated runtimes
.\install.bat
macOS / Linux · integrated runtimes
chmod +x install.sh && ./install.sh
OpenClaw / Hermes Agent · skills-only
.\install-openclaw.bat
.\install-hermes.bat

bash ./install-openclaw.sh
bash ./install-hermes.sh

即使 CLI 尚未安装，也会先准备文件。

如果 PATH 中没有对应可执行文件，Olympus 只跳过 MCP 注册等依赖 CLI 命令的步骤。之后安装 CLI，再运行同一个安装器即可。

  • 环境要求: Git 与 Node.js LTS
