# Layout Anatomy: Skill Olympus Pages v6

## Header

Sticky single row. Brand left, section links center, locale and GitHub action right. Mobile retains brand,
locale access, and GitHub while removing section links.

## Hero

Asymmetric 7/5 split. Left holds version label, literal headline, and two actions. Right holds four factual
metrics and a terse explanation. No decorative illustration.

## System Overview

Full-width framed diagram. Integrated hosts form the upper rail, skills-only hosts sit in a qualified side
lane, Zeus owns the six-step center line, and Chronos/Mnemo span underneath.

## Workflow and Support

Workflow entry points use an indexed editorial list rather than cards. Support uses two unequal columns:
integrated surfaces first, skills-only hosts second, with limitations shown inline.

## Install and Footer

Install commands are grouped by TermSnap/default and explicit skills-only targets. Footer links to source,
release notes, license, and all locale routes.
