# Direction: Olympian Control Plane

## Selected Direction

Preserve the live site's dark editorial system and turn the central experience into a technical control
plane. Runtime hosts feed a single workflow rail; six delivery phases form the spine; Chronos and Mnemo
appear as continuous lower rails.

## Signature Risk

The one intentional aesthetic risk is a large pipeline diagram used as both brand scene and product
explanation. It replaces decorative hero imagery and must still collapse into a readable mobile sequence.

## Candidate Decision

Three new visual candidates are exempted because this is a delta redesign against an existing,
user-approved production page. The approved benchmark supplies the visual direction; only content
hierarchy, diagram structure, locale coverage, and readability change.
