# Brief: Skill Olympus Pages v6

## Problem

The live GitHub Pages site still describes v4.20.0, Gemini, 42 installed agents, and only two languages.
The README hero image also explains a Codex-specific Zeus pipeline rather than the current product surface.

## Scope

- Replace the README explanation image with one editable, accessible SVG.
- Preserve the approved dark editorial identity of the live site.
- Update the site for v6.0.0 and add Korean, English, Japanese, and Simplified Chinese routes.
- Distinguish four integrated CLIs from two skills-only hosts without overstating parity.
- Keep the page static, fast, and maintainable on the gh-pages branch.

## Decision

This is a delta redesign, not a greenfield style exploration. The existing live page is the visual
benchmark and the agreed direction is to modernize its information architecture.
