# Mnemo 비벡터 대화 맥락 회상 — 감리 기준

작성: 2026-10-05 / source: codex

이 문서는 구현 전에 작성한 설계가 아니라 이번 Argos 감리를 위해 기존 사용자 요구와
공개된 회상 규약을 모은 사후 대조 기준이다. 구현 결과에 맞춰 요구를 낮추거나
기존 검사를 독립적인 성능 평가로 취급하지 않는다.

## 범위와 출처

- 현재 대화: 일반 채팅에도 맥락이 있고, 기존 태그가 맥락을 담으며, 기본 검색은 비벡터로 유지한다.
- [회상 규약](../../../skills/mnemo/references/recall.md): 입력·출력·검색·연결·예산·한계의 정본.
- [프로젝트 저장 경계](../../../skills/mnemo/references/project-storage.md): 프로젝트 루트와 경로 경계.
- [069 결정](../../../memory/architecture/069-mnemo-nonvector-context-recall.md): 선택한 방향과 재검토 조건.
- [구현 인계](../../handoffs/2026-10-05-150801-mnemo-nonvector-recall.md): 변경 범위와 흐름도.
- [합성 평가 기록](../../../skills/mnemo/evals/recall-results.md): 기존 측정과 미측정의 구분.

대상은 공통 recall.py, 재사용 Markdown 함수, 공통 번들, 네 CLI 검색 규약과 격리
설치 경로다. 저장 훅·외부 저장소 전체·현재 사용자 홈 설치·릴리즈는 이번 감리 대상에
포함하지 않는다. 코드맵은 개발 소스 탐색에 사용하고 일반 대화 검색에는 요구하지 않는다.

## Requirements

| ID | 기존 계약 | 확인 방법 |
|---|---|---|
| R1 | 파일을 조회하는 도구이며 프로젝트 루트를 정규화한다. 기억·대화·설정·원본 세션을 수정하거나 생성하지 않는다. | CLI 격리 실행과 전후 파일 비교, 루트 회귀 검사 |
| R2 | 검색어·동의어는 호출자가 정한다. 예약 ID → 태그 → 제목 → 본문 순위이며 동률에서 일치 수·정제 기억·기록 날짜를 사용한다. 기간을 최근 7일로 제한하지 않는다. | 순위·태그 없는 대화·오래된 기록 검사 |
| R3 | 실제 대화 형식의 사용자 질문과 응답을 함께 반환하고 위치·실제 턴 식별자를 보존한다. 예제의 역할 표기를 대화 경계로 오인하지 않는다. | 네 CLI 형식·복수 질문·예제 경계 검사 |
| R4 | 기존 예약 태그, 대체·의존 관계, 근거 대화의 시각·행번호를 추적한다. 끊긴·모호한·프로젝트 밖 근거는 미해결로 표시한다. | 연결·변경 조건·경로 경계 검사 |
| R5 | 직접 후보 수, 링크 3단계·총 60개, 근거 파일당 3턴, JSON 문자 예산에 상한을 둔다. 본문 중간을 잘라 의미를 바꾸지 않는다. 생략을 공개한다. | 경계·순환·큰 본문·예산 검사 |
| R6 | `<private>` 구간은 검색과 출력에서 제외한다. 비공개 구간 때문에 뒤의 공개 대화를 누락하지 않는다. | 닫힌·미완료 비공개 구간과 공개 후속 대화 검사 |
| R7 | CURRENT는 미대체 상태이고 사실 판정이 아니다. 적용 조건·현재 사용자 정정·reopen-when을 현재 에이전트가 판단한다. 이웃 턴은 adjacent-unverified로 표시한다. | 상태·이웃 표시·규칙 정본 대조 |
| R8 | 새 DB·임베딩·추가 LLM·등록 스킬·훅을 만들지 않는다. Python 3.9+·Node와 기존 설치 composition point를 사용한다. | 의존·번들·설치 정책 검사 |
| R9 | 네 CLI의 격리 설치본에서 조회 도구와 필수 지원 파일이 실제 실행된다. 공통 Markdown 추출이 기존 닥터를 회귀시키지 않는다. | 설치·번들·닥터 기존 검사 |
| R10 | 합성 근거 수집 성공률과 실제 최종 답변 정확도·실사용 속도를 구분하고 미실행을 공개한다. 문서의 수치는 실제 실행과 일치한다. | 평가 재실행·문서 대조 |

## 감리 제한

사후 기준서이므로 사전 설계의 CPS 추적성이나 완료 장부 이행을 증명하지 않는다.
이 기능은 로컬 CLI이며 HTTP API·MCP 도구·UI·도메인사전을 추가하지 않았다.
독립 holdout·최종 LLM 답변 평가는 별도 증거가 없으면 NOT RUN으로 유지한다.
