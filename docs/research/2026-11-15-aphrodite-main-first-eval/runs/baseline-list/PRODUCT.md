# PRODUCT.md — 발주 관리

## 승인된 대상과 과업
중소 제조사의 구매 담당자가 납기 지연 발주를 찾아 담당자를 배정하는 업무용 웹앱이다. 첫 과업은 목록에서 지연 건과 금액·납기를 확인하고 하나 이상 선택해 담당자를 배정하는 것이다. 데스크톱을 주로 쓰며 외근 중에는 폰에서도 확인한다. 역할은 구매 담당자 하나이며 이 평가의 모든 데이터는 prototype이다.

## 이번 화면과 승인된 기능
발주 목록을 설계한다. 앱 탐색 대상은 발주·거래처·입고·보고서·설정이며 워크스페이스 전환과 계정 메뉴가 있다. 발주 검색(번호·거래처), 상태 필터, 거래처 필터, 기간 선택, 정렬, 필터 초기화, 새 발주, CSV 내보내기, 새로고침, 보관함, 화면 도움말을 사용할 수 있어야 한다. 목록의 각 발주에는 상세 열기·담당자 변경·보관이 있고 복수 선택 시 일괄 담당자 배정이 있다. 필수 기능은 새로 만들거나 삭제하지 않는다. 조작 후 피드백과 검색 결과 없음 상태도 설계한다.

## 범위 제외
