# 화면·과업 연결 — 발주 목록

Source Mode: product-derived. 설계 대상은 발주 목록 한 화면이며, 대화상자·완료 모습은 이 화면의 상태다. 별도 설계 페이지가 3개 이상인 경우가 아니므로 Mermaid 모듈은 사용하지 않았다.

## 현재 위치와 탐색

- 워크스페이스 전환 → 구매 워크스페이스 컨텍스트
- 주 메뉴 → **발주(현재)** / 거래처 / 입고 / 보고서 / 설정
- 계정 메뉴 → 구매 담당자
- 발주 목록 → 새 발주 작성 화면 진입점
- 목록 도구 → CSV 내보내기 / 새로고침 / 보관함 / 화면 도움말
- 각 발주 → 상세 열기 / 담당자 변경 / 보관

거래처·입고·보고서·설정·새 발주·워크스페이스·계정·보관함은 승인된 외부 목적지의 진입점을 유지한다. 이들의 내부 화면을 새로 설계하지 않는다. HTML에서는 상태 시트의 이름 있는 연결 명세로 이동하고 목록 복귀 링크를 제공한다. 보고서 메뉴가 있다는 이유로 신규 통계나 대시보드를 추가하지 않는다.

| 화면·상태 | 임무 | 진입 | 다음 |
|---|---|---|---|

## 정상 과업

발주 목록 → 지연 3건 보기 → PO-261101·PO-261103 선택 → 담당자 배정 → 김민수 선택 → 배정하기 → orders-assigned: 두 행의 담당자=김민수, 상태=지연, 알림=2건 배정 완료.

## 실패·복구

- 검색 “없는거래처” + 상태=지연 → 결과 0건 + 적용 조건 유지 → 검색·필터 초기화 → 원래 12건.
- 배정 중 실패 → 원래 담당자 유지 + 대화상자의 담당자·선택 유지 → 다시 배정하기 또는 취소.
- 재조회 실패 → 이전 결과 표시 경고 → 다시 불러오기 → 새 결과를 확인하고 선택.
- 보관 후 잘못 보관한 것을 발견 → 되돌리기 → 같은 발주를 목록에 복귀.
