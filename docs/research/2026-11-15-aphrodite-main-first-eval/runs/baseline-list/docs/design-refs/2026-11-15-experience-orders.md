## Page Goal

- 사용자가 이 화면에서 달성할 결과: 지연 발주를 찾아 납기·금액·현재 담당자를 확인하고 하나 이상에 담당자를 배정한다.
- 제품이 얻어야 하는 결과: 선택·처리 결과가 분명하고 실패에서도 동일 맥락으로 업무를 이어간다. 가상의 생산성 수치를 만들지 않는다.
- 관찰 가능한 성공 조건:
  1. 1280×800에서 제목·검색·지연 진입·필수 비교 열과 선택 컨트롤이 보인다.
  2. 390×844에서 발주별 필수 정보를 가로 스크롤 없이 읽는다.
  3. 상태=지연으로 좁히면 3건이며 적용 상태와 결과 수가 함께 보인다.
  4. PO-261101·PO-261103을 선택해 김민수로 배정하면 두 행의 담당자와 완료 알림이 일치한다.
  5. 검색 결과 0건에서 조건을 확인하고 한 번의 초기화로 12건으로 복귀한다.
  6. 승인된 모든 기능에 이름 있는 진입점이 있으며 신규 KPI·통계·AI·실제 서버 연결이 없다.

## Audience and Tasks

- 주요 사용자와 사용 상황: 중소 제조사 구매 담당자. 책상에서는 여러 행을 비교하며 외근 중에는 폰에서 발주를 확인한다.
- 최우선 과업: 지연 발주 찾기 → 금액·납기·담당자 확인 → 하나 이상 선택 → 담당자 배정 → 결과 확인.
- 시작 조건과 완료 조건: 샘플 12건이 있는 목록에서 시작하며, 선택한 행의 담당자 변경과 일치하는 완료 알림으로 끝난다.
- 주요 불안·마찰·실패 가능성: 선택 범위 착각, 기존 담당자 덮어쓰기, 필터 때문에 행이 보이지 않는 상황, 실패 후 선택 손실.

## Section Order

1. 앱 탐색과 현재 위치: 지금 어느 워크스페이스의 발주인지 구분한다.
2. 페이지 머리: “발주 목록”, 샘플 고지, 새 발주 진입점으로 범위를 알린다.
3. 검색·상태·상세 필터·정렬: 처리할 후보를 좁힌다.
4. 결과 수·지연 바로가기·목록 도구·적용 조건: 무엇이 보이는지 확인한다.
5. 선택바: 선택이 있을 때만 범위와 담당자 배정을 노출한다.
6. 결과 표 또는 모바일 발주 묶음: 금액·납기·상태·담당자를 비교하며 선택한다.
7. 선택 대화상자·완료 알림: 실행 직전 범위 확인과 실행 후 결과를 연결한다.

## CTA Strategy

- Primary: “담당자 배정” — 하나 이상 선택할 때 선택바에 한 번 등장하며 배정 대화상자를 연다. 대화상자는 “배정하기” 한 개의 솔리드 행동을 갖는다.
- Secondary: 기본 상태의 “지연 3건 보기”는 상태 필터를 지연으로 바꾸고 “전체 상태 보기”로 복귀할 수 있다. “새 발주”는 머리의 아웃라인 진입점이다.
- 반복 규칙: 일괄 배정은 선택바에만 두고 행의 “담당자 변경”은 해당 한 건을 같은 대화상자로 보낸다. 모바일 선택바는 top:0 sticky이며 별도 하단 복제 버튼을 만들지 않는다.
- 완료·실패 피드백: 완료 알림에 처리 건수·담당자를 표시하고 행 값을 바꾼다. 실패 시 대화상자에서 선택과 입력을 유지하고 “다시 배정하기”를 제공한다. 취소는 변경 없이 목록으로 돌아온다.

## Trust Strategy

- 사용자가 불안을 느끼는 지점: 복수 선택 후 담당자 덮어쓰기 직전, 보관 직전, 재조회가 실패한 상태.
- 그 직전에 제시할 근거: 선택 건수·발주번호·거래처·현재 담당자, 기존 담당자도 변경된다는 확인 문구, 보관할 발주번호, 이전 결과 표시 경고.
- 출처·날짜·검증 가능성: 샘플 원문은 PRODUCT.md, 확인일 2026-11-15. 운영 갱신 시각은 제공되지 않았다.
- 근거가 없을 때 생략할 요소: 보장 배지, 납기 달성률, 가상 성과, 자동 최신 상태 주장, 운영 시각·새 통계.

## Desktop Structure

- 기준 뷰포트: 1280×800.
- 첫 뷰포트: Sidebar 옆에 짧은 제목 머리 → 필터 한 행 → 결과 도구 → 표. 지연 3건을 기본 정렬의 첫 세 행에 두고 필수 7개 정보와 선택·행 메뉴를 유지한다.
- 그리드·pane·콘텐츠 위계: 176px 탐색 + 남은 메인, 메인 좌우 24px. 표의 금액은 우측 정렬, 발주번호·납기는 일정 폭, 품목은 가변 폭이다. 데이터가 화면의 주인공이다.
- 스크롤 흐름과 밀도 변화: 표는 12건 전체를 같은 행 높이로 표시한다. 뷰포트 하단 밖 행은 세로 스크롤로 확인한다. 제공되지 않은 페이지 크기·가짜 페이지네이션을 만들지 않는다.
