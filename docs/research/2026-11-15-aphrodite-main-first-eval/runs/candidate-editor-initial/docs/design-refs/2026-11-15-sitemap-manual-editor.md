# 화면·내비게이션 — 사내 매뉴얼 편집기

제품 화면은 문서 편집기 하나이며 내용 있음과 새 문서의 빈 상태를 각각 그린다. 추가 페이지를 만들지 않는다.

| 화면·상태 | 단일 임무 | 파일 |
|---|---|---|
| 내용 있는 편집기 | 제목·본문 수정 → 저장 상태 확인 → 미리보기 | wireframe-editor.html |
| 새 문서 빈 상태 | 제목·첫 문장 입력 → 저장 | wireframe-empty.html |
| 주요 상태 시트 (설계 문서) | 같은 편집기의 loading/error/success/permission/stale 표현 검토 | wireframe-states.html |

## 위치와 행동의 연결

| 범위 | 데스크톱 | 모바일 |
|---|---|---|
| 앱 전체 | 좌측 탐색: 워크스페이스·최근 문서·팀 폴더·템플릿·즐겨찾기·계정 | 헤더의 탐색 펼침 안에 같은 대상 |
| 문서 | 제목 입력·저장 상태·저장 | 같은 헤더, 본문보다 먼저 |
| 본문 | 본문 직전 도구 모음: 문단 스타일·굵게·기울임·목록·링크·표 삽입 | 서식·삽입 펼침, 본문 위 한 행 |
| 문서 읽기 확인 | 도구 모음 미리보기 | 같은 행 미리보기 |
| 문서 보조 행동 | 더보기: 공유·버전 기록·댓글·내보내기·문서 설정 | 같은 더보기 |
| 본문 찾기 | 도구 모음 본문 검색 | 찾기 펼침의 본문 검색 |
| 문서 점검 | 하단 문서 정보·확대 비율 | 같은 하단 접이식 조작 |

## 과업 흐름

- 기존 문서 진입 → 제목·본문 확인 → 입력 → 저장 전 상태 → 저장 → “저장 중…” → “모든 변경사항 저장됨” → 미리보기.
- 새 문서 진입 → 제목 입력 → “본문” 입력란에 첫 문장 → 저장 → 같은 작업면에 저장 완료 상태.
- 저장 실패 → 입력 내용 유지 → 실패 안내 옆 “다시 저장” → 저장 중 → 저장됨.
- 미리보기 → 편집으로 돌아오기. 별도 페이지 없이 편집 작업면을 미리보기 상태로 바꿀 것을 권장한다.
- 읽기 권한 변화 → 작업면은 읽기전용, 저장 비활성 → 내용 보존·권한 요청 안내.
- 오래된 문서 → 본문 위 경고 → 내 변경 유지 → 최신 문서 확인·비교 결정. 자동 덮어쓰기를 하지 않는다.

## 앱 탐색의 범위

최근 문서·팀 폴더·템플릿·즐겨찾기·워크스페이스·계정의 진입점을 보존한다. 해당 목적지의 상세 화면은 승인 범위 밖이므로 설계하지 않는다. 메뉴 옵션·서버 응답은 경험 계약의 structure 미결이다.

## 사이트맵 형식

두 제품 상태만 있으므로 Phase 2-1의 “페이지가 3개 이상” Mermaid 조건은 적용되지 않는다. 상태 시트는 제품 페이지로 세지 않는다.
