# 화면·내비게이션 — 사내 매뉴얼 편집

제품 화면은 하나의 문서 편집기이며, 파일 두 개는 내용 있음/새 문서 상태를 구분한다. 상태 시트는 검토 자료이며 제품 내 새 화면이 아니다. 3개 이상 페이지가 아니므로 Mermaid 사이트맵은 NOT APPLICABLE.

| 식별자 | 파일 | 단일 임무 | 진입 | 다음 행동 |
|---|---|---|---|---|
| editor | [editor.html](editor.html) | 기존 매뉴얼 제목·본문 수정과 저장 상태 확인 | 팀 폴더·최근 문서·문서 링크 | 본문 수정 → 저장 → editor-saved |
| empty | [empty.html](empty.html) | 첫 문장을 쓰기 시작 | 새 문서 | 제목·본문 입력 → 저장 → 같은 편집기의 저장 완료 상태 |
| editor-saved | editor의 success 상태 | 결과와 보존 여부 확인 | 저장 완료 | 미리보기 또는 계속 편집 |

## 탐색과 조작의 범위

- 앱 전체: 좌측 워크스페이스 전환 → 새 문서 → 최근 문서·팀 폴더·템플릿·즐겨찾기 → 계정. 모바일에서는 “앱 탐색 열기”로 같은 구성을 연다.
- 현재 문서: 제목·저장 상태 → 저장·미리보기·문서 메뉴. 폰의 미리보기는 문서 메뉴 첫 항목.
- 본문: 문단 스타일·굵게·기울임 → 목록·링크·표 → 본문 찾기. 폰의 목록·링크·표는 서식 메뉴.
- 하단: 문서 정보·확대 비율. 댓글·버전 기록·공유·내보내기·문서 설정은 문서 메뉴에서 같은 편집 화면 위 대화상자로 열린다.

## 과업 흐름

정상: 현재 문서 식별 → 제목/본문 수정 → 저장하지 않은 변경사항 → 저장 중 → 모든 변경사항 저장됨 → 미리보기 → 닫고 수정으로 복귀.

첫 사용: 새 문서 → 문서 제목 입력 → 작성 시작/본문 직접 입력 → 저장 활성화 → 저장 → 같은 작업면의 저장 완료 모습. 제목이 없으면 제목 필드 오류로 연결하며 작성 본문을 남긴다.

실패: 저장 실패 → 본문 유지 + “다시 저장” → 저장 중 → 저장 완료. 권한 변경은 읽기 전용과 문서 정보, 오래된 버전은 본문 유지와 버전 기록으로 연결한다. 권한·충돌의 서버 정책은 Experience Contract의 Open Decisions에 남겼다.
