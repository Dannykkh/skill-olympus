# PRODUCT.md — 사내 매뉴얼 편집기

## 승인된 대상과 과업
운영 담당자가 팀 매뉴얼 문서를 열어 제목과 본문을 고치고 저장·미리보기하는 업무용 웹앱이다. 데스크톱을 주로 쓰며 폰에서 짧은 수정도 한다. 역할은 편집 권한이 있는 담당자 하나다. 이번에 문서 편집 화면과 새 문서의 빈 상태를 설계한다.

## 승인된 기능
앱 탐색 대상은 최근 문서·팀 폴더·템플릿·즐겨찾기이며 워크스페이스 전환과 계정 메뉴가 있다. 문서 기능은 제목 수정·저장 상태 확인·저장·미리보기·공유·버전 기록·댓글·내보내기·문서 설정이다. 본문 편집 기능은 문단 스타일·굵게·기울임·목록·링크·표 삽입이며 본문 검색·확대 비율·문서 정보 확인도 필요하다. 모든 기능을 사용할 수 있게 설계하되 화면을 더 만들거나 승인된 기능을 삭제하지 않는다.

# 입고 검사 매뉴얼
이 문서는 입고된 부품의 검사와 기록 절차를 정리합니다.
## 1. 입고 확인
거래명세서의 발주번호와 실제 수량을 대조합니다.
포장 손상이나 품목 차이가 있으면 사진과 함께 기록합니다.
## 2. 외관 검사
검사 표본을 추출하고 균열·오염·변형을 확인합니다.
이상 항목은 불량 유형과 수량을 입력합니다.
## 3. 기록과 보관
검사가 끝나면 검사 기록을 저장하고 담당자에게 공유합니다.
보류된 부품은 지정 구역으로 이동합니다.

## 범위 제외
마케팅 페이지·성과 KPI·AI 요약·실제 협업 서버·인증·결제는 제외한다. 문서 없는 상태에도 사용자가 첫 문서를 쓰기 시작할 수 있어야 한다. 이 문서의 대상·기능·제외는 모두 사용자 승인된 평가 전제다.
