# 페이지·과업 지도 — 발주 목록

상세 설계는 발주 목록 한 페이지와 같은 페이지의 확인·결과·회복 상태다. 상태 시트의 카드는 별도 앱 페이지로 계산하지 않는다. 승인된 전역 목적지는 탐색 연결 경계이며 본문 화면을 추가 설계하지 않는다.

| 대상 | 단일 임무 | 위치·다음 행동 |
|---|---|---|
| 발주 목록 | 지연 발주 식별·비교·선택 | 활성 앱 내비 발주 → 목록 도구·행 작업 |
| 배정 확인 | 대상·기존 담당자·새 담당자 확인 | 담당자 배정 → 3건 배정 |
| orders-assigned | 변경 결과 확인 | 3건 이서연 배정 확인 → 목록 |
| 검색 결과 없음 | 조건 수정으로 회복 | 검색어 수정 / 검색·필터 초기화 |
| 오류·최신화·권한 | 실패 원인·회복 | 재시도 / 새로고침 / 워크스페이스 전환 |
| 거래처·입고·보고서·설정 | 해당 업무로 이동 | 앱 내비, 연결 경계만 표시 |
| 새 발주 | 작성 흐름 진입 | 페이지 헤더, 작성 필드는 후속 정의 |
| 보관함 | 보관 결과 확인 | 목록 더보기 → 보관함 |

정상: 목록 → 상태 지연 → 대상 선택 → 담당자 배정 → 기존 담당자 확인 → 3건 배정 → orders-assigned.
실패: 배정 실패 → 선택·입력 유지 → 다시 시도. 검색0건 → 조건 요약 → 초기화 → 목록.
보관: 해당 행 작업 → 발주번호 확인 → 보관 → 보관 완료 → 보관함.

데스크톱은 앱 사이드바, 모바일은 상단 메뉴 펼침으로 전역 탐색을 대체한다. 현재 발주에는 aria-current=page·회색 배경을 함께 쓴다. 워크스페이스·계정은 앱 영역에 두고 목록 도구와 섞지 않는다.
