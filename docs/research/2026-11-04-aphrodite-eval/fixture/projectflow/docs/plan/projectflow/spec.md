# 플로우보드 MVP — spec

## Context Map

### 공유 전제
- 목표: 소규모 팀이 가입 당일 첫 프로젝트를 만들고 팀원을 초대해 첫 할 일을 배정하게 한다
- 산업: 협업 SaaS | 범위: MVP
- 성공 기준: 가입 후 24시간 안에 첫 프로젝트를 만드는 계정 비율 60% 이상 (현재 30%)

### 이해관계자
| 역할 | 설명 | 관련 섹션 |
|------|------|-----------|
| 팀 리더 | 팀을 만들고 프로젝트를 여는 사람 | 01-onboarding |
| 팀원 | 초대받아 할 일을 처리하는 사람 | 02-board |

### 시스템 역할 (Role Inventory)
| 역할 ID | 표시명 | 주요 업무 | 금지 행동 | 화면 | 인증 주체 | 상위 역할 |
|---------|--------|-----------|-----------|------|-----------|-----------|
| owner | 팀 소유자 | 팀·프로젝트 생성, 초대, 설정 | - | 공용 권한차등 | 사람 | - |
| member | 팀원 | 할 일 처리, 댓글 | 팀 설정 변경, 팀원 내보내기 | 공용 권한차등 | 사람 | owner |

### 에코시스템 맵
| 시스템 | 대상 | 연동 방식 | 관련 섹션 |
|--------|------|-----------|-----------|
| 이메일 | 팀원 초대 | 외부API | 01-onboarding |
| Slack | 알림 | 제외 | - |

### 기존 환경
React 18 + Vite SPA, REST API, 인증은 이메일 링크.

## Problem Statement

| # | 핵심 문제 | 영향 | 우선순위 | 해결 섹션 |
|---|-----------|------|----------|-----------|
| P1 | 가입 직후 계정에는 프로젝트가 0개라 빈 화면에서 무엇을 할지 몰라 이탈 | 가입자 70%가 첫 프로젝트 전에 이탈 | 🔴 필수 | 01-onboarding |
| P2 | 팀원 초대 경로가 설정 메뉴 깊숙이 있음 | 혼자 쓰다 그만둠 | 🟠 중요 | 01-onboarding |
