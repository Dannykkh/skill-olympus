# 아테나 전략 검토 — 플로우보드

## 판정 요약
| 항목 | 판정 |
|------|------|
| 결론 | CONDITIONAL GO |
| 조건 | 첫 프로젝트 생성률 개선에 집중하고 관리자 분석 기능은 미룬다 |
| 수요 | Moderate |

### 추천 MVP 기능 (Reduce 결과)
| # | 기능 | 이유 |
|---|------|------|
| 1 | 프로젝트 생성 마법사 | 없으면 첫 가치에 도달하지 못함 |
| 2 | 팀원 초대 | 혼자 쓰면 협업 도구의 가치가 없음 |
| 3 | 할 일 보드 | 핵심 가치 제안 |

### 삭제 권고 기능
| 기능 | 삭제 이유 | 복구 시점 |
|------|-----------|-----------|
| 팀 성과 KPI 대시보드 | 프로젝트가 쌓이기 전에는 보여줄 데이터가 없고 초기 사용자 과업과 무관 | 활성 팀 100개 이후 |
| 시간 추적 | 경쟁 제품 대비 차별화가 아님 | 유료 전환 검증 이후 |
