> **작성 기준**: 개인정보보호법 제30조(개인정보 처리방침의 수립 및 공개)
> **작성 방법**: 2026-08-08 기준 저장소 코드 전수 조사 결과만 반영. 코드에 없는 내용은 지어내지 않고 `[빈칸: ...]`으로 표시.
> **주의**: 이 문서는 법률 자문이 아닌 초안입니다. 시행 전 개인정보보호 전문가/변호사 검토를 권장합니다.

**Skill Olympus(스킬 올림푸스)** (이하 "본 프로그램")은 개인정보보호법에 따라 이용자의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 수립·공개합니다.

본 프로그램은 이용자의 로컬 PC에 설치되어 동작하는 CLI 확장 도구이며, **개발자가 운영하는 서버로 이용자의 데이터를 수집·전송하지 않습니다.** 아래에 기술된 모든 저장은 이용자 본인의 PC 안에서 이루어집니다.

## 제1조 (수집하는 항목과 수집 목적)

| 수집 항목 | 수집 시점 | 수집 목적 | 저장 위치 (이용자 PC 내) |
|---|---|---|---|

## 제2조 (보유 및 이용 기간)

- 현재 코드상 자동 보존기간 제한이 **없습니다**. 저장된 파일은 이용자가 직접 삭제하기 전까지 무기한 보존됩니다.
- 관찰 로그(`observations.jsonl`)는 10MB 초과 시 `archive/` 폴더로 이동될 뿐 삭제되지 않습니다.
- [빈칸: 보유 기간 정책을 정해야 합니다. 예: "수집일로부터 N년 보관 후 파기" 또는 "이용자가 삭제할 때까지 보관" 중 택일하여 명시]

## 제3조 (파기 절차와 파기 방법)

- 현재 자동 파기 기능이 **없습니다**. 파기는 이용자가 아래 파일/폴더를 직접 삭제하는 방식으로 이루어집니다:
  - `conversations/`, `memory/`, `docs/handoffs/`, `docs/chronos/`, `.orchestrator/` (orchestrator DB는 `orchestrator_reset` 도구로 초기화 가능)
  - 전역 로그: `~/.codex/hooks/save-turn-debug.log`, `<프로젝트>/.claude/mnemo-errors.log`
- 프로그램 제거(`install.bat --uninstall`)는 훅 **설정만** 제거하며, 이미 저장된 데이터는 삭제하지 않습니다.
- [빈칸: 파기 절차(자동 파기 주기 또는 언인스톨 시 데이터 삭제 옵션)와 파기 방법(파일 완전 삭제 등)을 정책으로 명시해야 합니다]

## 제8조 (자동 수집 장치와 거부 방법)

- 본 프로그램은 웹 서비스가 아니므로 **쿠키를 사용하지 않습니다**.
- 대신 CLI 훅에 의한 **대화·도구 사용 기록 자동 저장 장치**가 동작합니다:
  - 저장 훅(save-conversation, save-response, save-tool-use, save-turn 등)은 설치 시 컴포넌트 선택과 무관하게 **항상 설치**되며, 기본값은 저장 활성화입니다.
  - **거부 방법 1 (저장 opt-out)**: 환경변수 `MNEMO_DISABLE=1`(또는 `true`/`yes`)을 설정하면 대화·도구 기록·backfill 자동 저장 전체가 중단됩니다 (기존 저장분은 유지). 특정 프로젝트만 끄려면 해당 프로젝트 `.claude/settings.json`의 `env` 블록에 설정합니다.
  - **거부 방법 2 (버전 확인 opt-out)**: 환경변수 `OLYMPUS_UPDATE_CHECK_DISABLE=1`을 설정하면 세션 시작 시 GitHub로 나가는 자동 버전 확인 요청이 중단됩니다.
  - **거부 방법 3 (완전 제거)**: `install.bat --uninstall` 실행 시 훅 설정이 제거되어 이후 저장이 중단됩니다 (기존 저장분은 유지).
  - **거부 방법 4 (부분 마스킹)**: 대화 중 `<private>...</private>` 태그로 감싼 내용은 `[PRIVATE]`로 치환되어 저장됩니다. 단, 이 마스킹은 대화 본문에만 적용되며 **도구 사용 관찰 로그(observations.jsonl)에는 적용되지 않습니다.**
