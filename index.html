01 / SYSTEM MAP

무엇이 어디까지 연결되는지 먼저 보여줍니다.

모든 호스트를 똑같이 지원한다고 말하지 않습니다. 런타임 통합이 검증된 네 CLI와, 이식 가능한 스킬만 설치하는 두 호스트를 분리합니다.

Integrated

Claude Code, Codex CLI, Antigravity CLI, Grok Build는 런타임별 설치, 기억, 오케스트레이션 계약을 따릅니다.

Skills-only

OpenClaw와 Hermes Agent에는 활성 스킬 18개와 source-only 모듈 76개만 설치합니다.

02 / ENTRY POINTS

필요한 깊이만 호출합니다.

평소에는 18개 진입점만 보입니다. 세부 전문 지식 76개는 요청에 맞을 때 카탈로그에서 직접 읽습니다.

01Zeus/zeus

한 문장에서 설계, 구현, 감리, 실행 환경, 테스트, 근거 보고까지 진행합니다.

02Zephermine/zephermine

구현 전에 요구사항, API, QA 시나리오, 흐름도를 고정합니다.

03Poseidon/agent-team

현재 CLI의 네이티브 작업자에게 파일 소유권을 나눠 병렬 구현합니다.

04Aphrodite/aphrodite

사용자 과업에서 시작해 디자인 계약, 구현, 실제 렌더 검증까지 맡습니다.

05Argos/argos

설계 산출물과 구현을 대조해 근거가 있는 준공 판정을 냅니다.

06Minos/minos

Playwright 시나리오를 실행하고 재현 가능한 실패를 통과할 때까지 고칩니다.

07Chronos/chronos

외부 검증이 완료 계약을 만족할 때까지 한 이슈씩 이어갑니다.

08Mnemo/mnemo

과거 대화와 결정을 찾고 다음 세션이 이어받을 수 있는 상태를 남깁니다.

04 / INSTALL

TermSnap은 한 번에, 다른 호스트는 명시적으로.

기본 설치는 Claude, Codex, Antigravity, Grok을 준비합니다. OpenClaw와 Hermes Agent는 별도 설치기로 필요한 스킬만 넣습니다.

Clone
git clone https://github.com/Dannykkh/skill-olympus.git
cd skill-olympus
Windows · integrated runtimes
.\install.bat
macOS / Linux · integrated runtimes
chmod +x install.sh && ./install.sh
OpenClaw / Hermes Agent · skills-only
.\install-openclaw.bat
.\install-hermes.bat

bash ./install-openclaw.sh
bash ./install-hermes.sh

CLI가 아직 없어도 자산부터 준비합니다.

실행 파일이 PATH에 없으면 MCP처럼 CLI 명령이 필요한 단계만 건너뜁니다. 나중에 CLI를 설치한 뒤 같은 설치기를 다시 실행하면 됩니다.

  • 업데이트: git pull 후 설치기를 다시 실행
  • 전체 노출: --include-source-only-skills 사용
  • 충돌 보호: 수정된 동명 스킬은 _olympus-preserved로 이동
  • 요구사항: Git과 Node.js LTS
