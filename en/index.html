01 / SYSTEM MAP

See exactly what connects, and how far.

Olympus does not call every host fully integrated. Four runtimes have verified integration contracts; two additional hosts receive the portable skill surface only.

Integrated

Claude Code, Codex CLI, Antigravity CLI, and Grok Build follow runtime-specific installation, memory, and orchestration contracts.

Skills-only

OpenClaw and Hermes Agent receive 18 active skills and 76 source-only modules.

02 / ENTRY POINTS

Invoke only the depth you need.

Only 18 entry points stay visible. Seventy-six specialist modules are read from the catalog when the request actually needs them.

01Zeus/zeus

Take one sentence through planning, implementation, inspection, runtime setup, testing, and an evidence report.

02Zephermine/zephermine

Freeze requirements, APIs, QA scenarios, and flow diagrams before implementation.

03Poseidon/agent-team

Split file ownership across the current CLI's native workers for parallel implementation.

04Aphrodite/aphrodite

Move from user tasks to an experience contract, implementation, and real render review.

05Argos/argos

Compare implementation against design artifacts and issue an evidence-backed acceptance decision.

06Minos/minos

Run Playwright scenarios and repair reproducible failures until the checks pass.

07Chronos/chronos

Continue one issue at a time until external evidence satisfies the completion contract.

08Mnemo/mnemo

Find past conversations and decisions, then leave resumable state for the next session.

04 / INSTALL

One TermSnap setup. Explicit portable hosts.

The default installer prepares Claude, Codex, Antigravity, and Grok. OpenClaw and Hermes Agent use dedicated skills-only installers.

Clone
git clone https://github.com/Dannykkh/skill-olympus.git
cd skill-olympus
Windows · integrated runtimes
.\install.bat
macOS / Linux · integrated runtimes
chmod +x install.sh && ./install.sh
OpenClaw / Hermes Agent · skills-only
.\install-openclaw.bat
.\install-hermes.bat

bash ./install-openclaw.sh
bash ./install-hermes.sh

Prepare assets before the CLI arrives.

If an executable is missing from PATH, Olympus skips only CLI-dependent commands such as MCP registration. Install the CLI later and rerun the same installer.

  • Update: git pull, then rerun the installer
  • Expose all: use --include-source-only-skills
  • Protect collisions: modified same-name skills move to _olympus-preserved
  • Requires: Git and Node.js LTS
