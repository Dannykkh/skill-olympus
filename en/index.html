Harness and Loop Engineering

Act → Observe → Verify

Agents don't run on a single prompt — they run on loops: act, observe, verify. Skill Olympus was built that way from the start.

Foundation

Harness

Zeus is the foundation. One non-interactive request is kept alive, decomposed, implemented, inspected, deployed, tested, and reported — without handing "next steps" back to you.

Operating Model

Loop

Chronos is the operating model on top of it. A verification gate that runs real tests (Chronos), fix-until-pass (Minos), AC cross-check (Argos), GO/NO-GO (Clio) — since v4.7.0 these loops run on the native /goal stop gate.

One Pipeline

Interview → Build → Audit → Ship
01 — Design
Zephermine asks first

Stakeholder interviews and domain analysis become a section-by-section build plan. Questions come before code.

02 — Build
Poseidon puts a team to work

Section dependencies are grouped into waves; an agent team implements them in parallel.

03 — Audit
Argos cross-checks

Spec, API contracts, QA scenarios, flow diagrams — the implementation is checked against every design artifact.

04 — QA
Minos sits in judgment

Generates Playwright tests from the QA scenarios and loops until they pass.

05 — Close
Clio writes it down

A final GO/NO-GO review, plus a PRD, technical docs, and a manual — generated in one pass.

Or, all at once

Run the five steps yourself, or hand Zeus a one-line brief and it finishes them in order — no questions asked.
