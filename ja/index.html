4つのCLIを、ひとつの開発システムに。

Claude Code、Codex、Antigravity、Grokで、同じ進め方を使えます。Zeusが設計から根拠付きレポートまでを束ね、Chronosが作業を止めず、Mnemoが判断を次のセッションへ引き継ぎます。

01 / SYSTEM MAP

どこまで連携するかを、先に示します。

すべてのホストを同じ水準で扱いません。ランタイム統合を検証済みの4つのCLIと、移植可能なスキルだけを導入する2つのホストを分けています。

Integrated

Claude Code、Codex CLI、Antigravity CLI、Grok Buildには、ランタイム別の導入、記憶、オーケストレーション契約があります。

Skills-only

OpenClawとHermes Agentには、有効なスキル18個とsource-onlyモジュール76個を導入します。

02 / ENTRY POINTS

必要な深さだけ呼び出します。

普段見えるのは18の入口だけです。専門モジュール76個は、依頼に必要なときだけカタログから読み込みます。

01Zeus/zeus

一文の依頼から、設計、実装、監査、実行環境、テスト、根拠レポートまで進めます。

02Zephermine/zephermine

実装前に要件、API、QAシナリオ、フロー図を固めます。

03Poseidon/agent-team

現在使っているCLIのネイティブワーカーにファイルの担当を割り振り、並列で実装します。

04Aphrodite/aphrodite

利用者の仕事から、体験設計、実装、実画面の確認までつなげます。

05Argos/argos

設計成果物と実装を照合し、根拠付きで合否を判定します。

06Minos/minos

Playwrightシナリオを実行し、再現した不具合をテストが通るまで直します。

07Chronos/chronos

外部の検証結果が完了条件を満たすまで、一件ずつ作業を続けます。

08Mnemo/mnemo

過去の会話と判断を探し、次のセッションが再開できる状態を残します。

03 / SUPPORT

対応範囲を正確に分けます。

スキル文書を読めることと、hooks、記憶、MCP、ネイティブワーカーまで連携することは、別の対応水準です。

統合ランタイム

スキルとランタイム別アダプターを一緒に導入し、検証します。

Claude Code
active 21、source-only 76、hooks、Mnemo、MCP、ネイティブsubagents
Codex CLI
active 20、source-only 76、notifyベースのMnemo、MCP、ネイティブworkers
Antigravity CLI
active 20、source-only 76、native Stop hooks、Mnemo、MCP、ネイティブworkflow
Grok Build
Claude互換層が共有するactive 21とsource-only 76、Grok用Mnemo

skills-only

ホストのAgent Skillsに、再利用できるスキル本体を導入します。

OpenClaw
active 18、source-only 76
Hermes Agent
active 18、source-only 76

plugins、hooks、Mnemo、MCP、独自エージェント、4つのCLI専用アダプターについて、同等の対応はうたいません。

04 / INSTALL

TermSnapは一括で。ほかのホストは明示的に。

標準インストーラーはClaude、Codex、Antigravity、Grokを準備します。OpenClawとHermes Agentには専用のskills-onlyインストーラーを使います。

Clone
git clone https://github.com/Dannykkh/skill-olympus.git
cd skill-olympus
Windows · integrated runtimes
.\install.bat
macOS / Linux · integrated runtimes
chmod +x install.sh && ./install.sh
OpenClaw / Hermes Agent · skills-only
.\install-openclaw.bat
.\install-hermes.bat

bash ./install-openclaw.sh
bash ./install-hermes.sh

CLIがなくても、先に資材を準備します。

実行ファイルがPATHになければ、MCP登録などCLIコマンドが必要な処理だけを飛ばします。CLIを導入したあと、同じインストーラーをもう一度実行してください。

  • 更新: git pullのあと、インストーラーを再実行
  • 全件を表示: --include-source-only-skillsを使用
  • 競合を保護: 変更済みの同名スキルは_olympus-preservedへ移動
  • 必要環境: GitとNode.js LTS
