# 심각도 기준 가이드 (P0~P3)

> SKILL.md에서 이동된 P0~P3 등급 판정 기준 및 리포트 출력 형식 상세 가이드

---

## 심각도 등급

| 등급 | 의미 | 점수 가중치 | 영향 |
|------|------|:-----------:|------|
| **P0** | 즉시 수정 | 5 | 검색 결과에 아예 안 나오거나, 모바일 검색 불가 |
| **P1** | 빠른 수정 | 3 | 검색 순위 하락, SNS 공유 미리보기 깨짐 |
| **P2** | 개선 권장 | 2 | 최적화 기회 누락, 사용자 경험 저하 |
| **P3** | 최적화 제안 | 1 | 미세한 개선, 경쟁사 대비 우위 확보 |

**P0은 해당 축을 40점(F)으로 상한 처리합니다.** `Disallow: /` 하나로 색인에서
사라지는 사이트가 "87점 B"로 표시되면 점수가 거짓말을 하기 때문입니다.

## 판정 상태 (status)

등급과 별개로, 각 항목에는 상태를 붙입니다.

| status | 계수 | 쓰는 때 |
|--------|:----:|--------|
| `pass` | 1.0 | 충족 |
| `warn` | 0.5 | 부분 충족 |
| `fail` | 0.0 | 미달 — **`file:line` 근거 필수** |
| `na` | 제외 | 이 프로젝트에 해당 없음 (블로그의 Product 스키마 등) |
| `unknown` | 제외 | 정적 분석으로 판정 불가 (런타임 헤더, 실제 렌더 결과 등) |

`na`와 `unknown`은 분자·분모 양쪽에서 빠집니다. 통과로도 감점으로도 치지 않고,
리포트에 건수만 표시해 점수의 신뢰 구간을 밝힙니다.

**근거를 못 찾았으면 `fail`이 아니라 `unknown`입니다.** 추측으로 감점하지 마세요.

[점수 모델 상세 → scoring-model.md](scoring-model.md)

## 영역별 P0/P1 판정 기준

### P0 즉시 수정 (검색 결과 노출 불가 수준)

| 영역 | 이슈 | 이유 |
|------|------|------|
| robots.txt | `Disallow: /` (전체 차단) | 검색 결과에 아예 안 나옴 |
| robots.txt | 파일 없음 | 크롤러가 기본 정책 사용, 의도치 않은 차단 가능 |
| Sitemap | 파일 없음 | 크롤러가 페이지를 누락할 수 있음 |
| 메타태그 | `<title>` 없음 | 검색 결과 제목 표시 불가 |
| 메타태그 | `viewport` 없음 | 모바일 검색 순위 직격 |
| AI 크롤러 | GPTBot/ClaudeBot 차단 | AI 검색(Perplexity, ChatGPT 검색)에서 완전 제외 |

### P1 빠른 수정 (검색 순위 하락 수준)

| 영역 | 이슈 | 이유 |
|------|------|------|
| robots.txt | `Sitemap:` 지시자 없음 | 크롤러가 sitemap을 못 찾음 |
| Sitemap | 공개 라우트 누락 | 크롤러가 페이지를 누락 |
| 메타태그 | 중복 title | 페이지 구분 불가 |
| 메타태그 | description 없음 | 검색 스니펫 자동 생성 (품질 저하) |
| 메타태그 | og:image 없음 | SNS 공유 미리보기 깨짐 |
| 메타태그 | canonical 없음 | 중복 콘텐츠 페널티 위험 |
| 메타태그 | `lang` 없음 | 언어 타겟팅 실패 |
| 이미지 | alt 없음 | 접근성 + 이미지 검색 순위 |
| 성능 | CSR 전용 (SSR/SSG 없음) | 검색 봇이 콘텐츠 못 읽음 |
| 성능 | 웹폰트 display:swap 없음 | FOIT (텍스트 안 보임) → CLS 영향 |
| AI 크롤러 | CSR 전용 | AI 크롤러가 콘텐츠 수집 불가 |
| AI 크롤러 | x-robots-tag: noai 과다 | 의도치 않은 AI 차단 |
| AEO | 질문형 헤딩 없음 | AI가 Q&A 패턴 인식 못함 |
| GEO | 수치/통계 없음 | AI가 인용 안 함 |
| GEO | 출처 표기 없음 | 신뢰도 낮은 소스로 판단 |
| GEO | 페이지 상단 핵심 답변 없음 | AI가 페이지 상단 우선 평가 |
| GEO | dateModified 없음 | AI가 최신성 판단 불가 |

## AEO/GEO 심각도 참고

검색 SEO 점수가 높아도 AI 가시성 점수는 낮을 수 있습니다. 두 축은 측정 대상이
다르므로, 반드시 **함께** 보고 액션 플랜을 세우세요.

AEO/GEO를 별개 분야로 서술하지 마세요. **AI 검색 표면에 적용된 SEO 기본기**입니다.
커뮤니티 권고가 Google 1차 자료와 충돌하면 1차 자료를 따르고, 충돌 사실을
리포트에 적습니다.

> **리포트에 수치를 인용할 때**: 이 스킬은 콘텐츠의 팩트 밀도와 출처 표기를
> 감사합니다. 리포트 자신이 출처 없는 수치를 쓰면 모순입니다.
> "AI 검색 트래픽이 N% 증가" 같은 시장 통계는 출처를 붙이거나 쓰지 마세요.
> 확인하지 못한 수치는 `[확인 필요]`로 표시합니다.
