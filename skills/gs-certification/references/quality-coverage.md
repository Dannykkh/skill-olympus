# 품질 영역 탐색표

공식 기준표의 누락을 찾기 위한 준비용 분류다. 이 표 자체는 인증기관의 전체 시험평가기준이 아니다.
선택 등급의 기준에서 요구된 항목만 REQUIRED로 확정하고 추가 진단은 ADVISORY로 구분한다.

| 영역 | 제품별 시험 설계 시 확인할 내용 | 증거 예 |
|---|---|---|
| 기능적합성 | 기능 목록·계산·조회·저장·예외 경로, 문서의 주장과 결과 일치 | 기능별 정상/오류 TC, 계산 대조 |
| 성능효율성 | 명시된 부하·용량·응답 시간·자원 사용, 측정 조건과 기준치 | 부하 설정, 원시 측정값, CPU/메모리 로그 |
| 호환성 | 지원 환경에서 공존·파일/API 연계·상호운용 | OS/브라우저/장비 매트릭스와 실행 결과 |
| 사용성 | 문서대로 과업 완료, 안내·오류·잘못된 입력·경계값·접근성 | 실제 UI 시험, 입력과 오류 메시지 |
| 신뢰성 | 연결 단절·재시작·장애·복구, 재시도와 중복 처리 | 장애 전후 데이터, 복구 및 정상 회귀 |
| 보안성 | 인증·인가·조직 경계·직접 요청·입력/필드 변조·민감정보 | 공통 API 보안 계약의 TC와 저장/효과 증거 |
| 유지보수성 | 진단·변경 영향·시험 가능성, 문서에 명시한 지원 기능 | 진단 로그, 변경 이력, 재현·회귀 명령 |
| 이식성 | 지원 환경 설치·설정·업데이트·제거·이전 | 깨끗한 환경 실행과 데이터 보존 정책 확인 |
| 일반적 요구사항 | 제품설명서·사용자취급설명서·제품 식별·지원 조건·제한사항 | 문서 위치와 실제 기능 대응표 |
| 업무적합성(2등급) | 기관 기준에 따른 대상 업무·결과·절차 적합성 | 업무 단위 TC, 기대 산출과 실제 산출 비교 |

웹은 UI와 직접 API를 함께 확인한다. 모바일은 실기기/에뮬레이터와 지원 OS·권한·오프라인 상태를,
패키지는 설치·업데이트·삭제·로컬 저장을, 임베디드는 해당 장비·펌웨어·I/O 및 장애 복구를 기준에
맞춰 선택한다. 장비를 확보하지 못하면 웹/정적 결과로 대체하지 않고 NOT RUN으로 남긴다.
